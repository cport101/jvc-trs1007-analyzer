# Changelog

## V2.0.0 - 2026-09-20

- Added robust two-pass logarithmic sweep fitting.
- Added adaptive FFT measurement windows.
- Added sub-bin spectral peak interpolation.
- Changed harmonic nomenclature from H2/H3 to HD2/HD3 throughout.
- Added sample-rate-dependent HD2/HD3 validity diagnostics.
- Retained legacy monotonic peak tracking as an automatic fallback.
- Retained automatic multi-pilot segmentation and sweep classification.
- Retained TRS-1007 inverse 75 microsecond high-frequency compensation.
- Removed obsolete duplicate plotting implementation.
- Added GitHub-ready README, requirements, license, example plot, and gitignore.
